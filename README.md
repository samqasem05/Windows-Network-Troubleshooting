# Windows Network Troubleshooting

PowerShell and Python scripts for troubleshooting common Windows networking issues.

## Skills Demonstrated

- PowerShell
- TCP/IP
- DNS
- DHCP
- SMB
- ICMP
- TCP port testing
- Windows network adapters
- Connectivity troubleshooting
- Basic Python networking

## Scripts

- `NetworkDiagnostic.ps1` - Checks adapter status, IP configuration, DNS, connectivity, TCP 445, and SMB access.
- `Networ-Troubleshooting.ps1` - Performs common Windows network troubleshooting and remediation tasks.
- `dhcp.ps1` - Checks the Windows DHCP Client service and returns its status.
- `TestConnection (2).py` - Performs basic Python-based connectivity testing.
